# GRC Risk Management System

GRC Risk Management System is a simple web application developed as a JavaScript learning project.

The application is designed to help users record and manage risks based on **Likelihood** and **Impact**, then calculate the corresponding **Risk Score** and **Risk Level**.

## Features

* Add new risk records
* Calculate risk scores based on Likelihood × Impact
* Determine risk levels
* Display risks in a table
* Edit risk records
* Delete risk records
* Search risks by name
* Filter risks by risk level
* Sort risks by risk score
* Store data using Local Storage
* Display risk statistics through a dashboard
* Calculate average risk score
* Visualize risk distribution using Chart.js
* Calculate risk percentages by risk level

## Risk Levels

| Score | Risk Level |
| ----: | ---------- |
| 17–25 | Very High  |
| 13–16 | High       |
|  8–12 | Medium     |
|   4–7 | Low        |
|   1–3 | Very Low   |

## Project Goal

This project is built as a hands-on JavaScript learning project, progressing from fundamental JavaScript concepts to the development of a web-based application using a **Governance, Risk, and Compliance (GRC)** use case.

The project will be developed incrementally to include frontend development, backend development, database integration, and REST API implementation.
